# Demo Script

## Story

The user wants to buy a shirt, but brand size charts and reviews are not enough because they forget
how similar clothes actually fit them.

## Flow

1. Open Mizaaj on a phone-sized viewport.
2. Show the private fit profile and sensitivities.
3. Capture a product page or size chart using text or camera upload.
4. Review extracted claims and approve them.
5. Ask for a fit recommendation.
6. Show the recommendation, confidence, risks, and evidence.
7. Log whether the item was kept, returned, or exchanged.
8. Show the private memory timeline getting stronger.

## Cognee Moment

Explain that Cognee is not a decorative RAG box. It is the durable private memory layer:

- remembers confirmed profile facts,
- remembers captured product facts,
- remembers purchase outcomes,
- recalls similar fit evidence for recommendations,
- supports forgetting private memory.

## Judge-Friendly Line

Mizaaj makes online shopping memory personal: every purchase, return, tag, and size chart becomes
private evidence for the next decision.
