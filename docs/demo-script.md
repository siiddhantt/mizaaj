# Demo Script

## Story

The user wants to buy clothes online, but brand size charts and reviews forget the most important
thing: what already worked or failed on their body and taste.

Mizaaj turns shopping evidence into private Cognee memory. When private memory is sparse, Mizaaj
Atlas adds a separate public evidence lane from curated product pages and size guides.

## Flow A: Returning User

1. Open Mizaaj signed in with Clerk.
2. Show the private profile: comfort flags, fit sensitivities, and taste notes.
3. Open the existing Bear House black tee product memory.
4. Show linked images, approved chat memory, and fit notes.
5. Ask: "Would a similar black relaxed tee work for me?"
6. Point out `Private memory` evidence: non-clingy chest/stomach fit, relaxed drape, subtle art.
7. Save a new outcome or memory card to show Cognee recall getting stronger.

## Flow B: New Product With Atlas

1. Attach a product-page screenshot for the SNITCH Coral Gardens oversized tee.
2. Ask: "What size should I start with and what measurements should I check?"
3. Show the answer labels:
   - `Current item`: extracted product context.
   - `Fit profile`: private body/taste guardrails.
   - `Mizaaj Atlas`: public SNITCH size chart from Cognee Cloud.
4. Emphasize the answer: Atlas gives S-XXL chest, shoulder, and length evidence, but private
   try-on outcomes will override it later.
5. Save the conversation to the product so the product identity gets richer.

## Cognee Moment

Explain that Cognee is not a decorative RAG box. It is the durable memory layer for two separate
knowledge lanes:

- private per-user memory for confirmed profile facts, product evidence, saved chats, and outcomes,
- public Mizaaj Atlas memory for curated product/size-guide evidence,
- recall that can be source-labeled in the UI,
- forgetting/rebuilding private memory without touching public Atlas.

Demo default: Cognee Cloud primary. Local Cognee and seed Atlas remain fallback paths.

## Judge-Friendly Line

Mizaaj makes online shopping memory personal: every tag, size chart, purchase, return, and try-on
note becomes recallable evidence for the next decision, with Cognee keeping private memory and
public Atlas cleanly separated.
